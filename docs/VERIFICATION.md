## 4. 最少必要的用户手工验收动作

1. **退出问题原始场景复测**：在安装 `0.2.0` 后，按你此前遇到“退出 app 好像还有问题”的习惯操作（直接点右上角 `×`、`Alt+F4`，或在运行文件哈希时退出）复测一次，确认你的原始触发路径已彻底消除。
2. **资源管理器物理鼠标拖放**：从 Windows 资源管理器用鼠标直接拖入一个本地文件到 `D01`、`D02`、`D03` 或 `I03` 工作区，确认跨窗口拖放高亮与载入手感。
3. **非 150% 显示缩放或交互式安装向导界面（可选）**：当前自动桌面实测在宿主 `150%` DPI 与 `/S` 原地覆盖模式下完成；如需检查 `100%`/`125%` 缩放或双击图形化 NSIS 向导页面，可手工双击安装包体验。
