### 复核浏览器离线读取

在仓库根目录运行 `npm ci` 和 `npm run build`。准备 Python、Playwright 与 Chromium 后，执行：

```sh
python -m pip install playwright
python -m playwright install chromium
python tests/qr_offline_smoke.py
```

可用 `--browser` 指定现有 Chromium 可执行文件。该测试覆盖生产资源、Worker、WASM 和浏览器图片剪贴板。桌面回归另用实际安装程序检查：

1. 用同一 Windows 用户覆盖安装，检查语言、主题与收藏，再正常退出。
2. 在 F01 复制二维码并粘贴到画图。保存为 PNG，再从 Explorer 拖回 WinKit，核对识别内容。
3. 断网后首次启动，读取同图多码样本和 WebP，核对各来源与识别结果。

### 4. 当时的用户手工实测建议（最多三项）

1. **坐标格式复制与近对跖测距体验**：在 `D10` 粘贴日常经纬度或 Apple / Google 地图坐标链接，体验八种格式复制与两点椭球测距。
2. **资源管理器拖入批量坐标文本**：在 `D10` 切到“批量转换”并从 Explorer 拖入含多行坐标的 `.txt` 文件，体验错误行定位与 CSV 导出。
3. **日常关窗复测**：在 `0.5.0` 覆盖升级后日常使用并关闭窗口，顺手确认此前反馈的偶发退出体验未再复现。
