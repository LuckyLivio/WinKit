## 4. 最少必要的用户手工实测建议（最多三项）

1. **资源管理器拖入表格/JSON 文件**：从 Explorer 直接将含多行引号或大整数编号的 `.csv` / `.json` 拖入 `D14` 工作区，体验自动识别方向、表格预览与另存流程。
2. **一次性净化剪贴板体验**：复制含 `utm_*` / `fbclid` 或跳转包装的链接（及混有普通文字的段落）点击 `D09` 剪贴板按钮，确认纯链接替换与非链接保持不变符合日常直觉。
3. **日常关窗复测**：在日常使用 `0.4.0` 后直接关闭窗口，确认此前偶发的退出体验问题未再出现。
