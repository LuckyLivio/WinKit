## 4. 最少必要的用户手工实测建议（最多三项）

1. **坐标格式复制与近对跖测距体验**：在 `D10` 粘贴日常经纬度或 Apple / Google 地图坐标链接，体验八种格式复制与两点椭球测距。
2. **资源管理器拖入批量坐标文本**：在 `D10` 切到“批量转换”并从 Explorer 拖入含多行坐标的 `.txt` 文件，体验错误行定位与 CSV 导出。
3. **日常关窗复测**：在 `0.5.0` 覆盖升级后日常使用并关闭窗口，顺手确认此前反馈的偶发退出体验未再复现。
