# WinKit 视觉规范与组件规则 (DESIGN.md)

## 1. 设计定位

WinKit 是面向 Windows 11 的本地桌面工具箱，视觉目标是克制、清楚、耐看的原生效率工具，而非营销落地页或后台管理模板。

- **优先浅色主题**，完整支持深色主题与跟随系统（`light` / `dark` / `system`）。
- **无营销噪音**：首页不设大尺寸 Hero、宣传口号、虚假统计或模拟记录；直接服务于检索、筛选与打开工具。
- **克制装饰**：禁止大面积蓝紫渐变、霓虹发光边框、多层毛玻璃堆叠、悬浮光球，以及机器人、魔法棒、星光等泛 AI 装饰图标；禁止“赋能”“释放生产力”等空泛措辞。
- **平台尊重**：保留 Windows 原生标题栏（拖动、最小化、最大化、关闭、Windows 11 贴靠布局），不模仿 macOS 红黄绿窗口控件，不为实验性透明材质引入不稳定插件。

## 3. 字体与排版

- **界面字体栈**：`"Segoe UI Variable Text", "Segoe UI", "Microsoft YaHei UI", system-ui, sans-serif`
- **等宽字体栈**：`"Cascadia Mono", "Consolas", ui-monospace, monospace`（用于 JSON 文本、行列号、SHA-256 摘要、图像像素尺寸与路径展示）
- **字号梯度**：
  - 页面主标题：`16px`，字重 `600`，行高 `24px`
  - 分区标题：`13px`，字重 `600`，行高 `20px`
  - 正文与控件：`13px`，字重 `400/500`，行高 `20px`
  - 代码与摘要：`12.5px`，字重 `400`，行高 `19px`
  - 辅助说明与徽章：`12px`，字重 `400/500`，行高 `16px`

## 4. 空间、尺寸与栅格

- **窗口参考尺寸**：默认 `1200×800`，紧凑基准 `1000×700`，最小窗口限制 `900×620`；兼容 100% / 125% / 150% 系统缩放。
- **框架尺寸**：
  - 左侧边栏宽度：`216px`（紧凑窗口下保持清晰单列导航）
  - 顶部工具栏高度：`52px`
- **间距标尺**：严格使用 `4px / 8px / 12px / 16px / 24px / 32px`
- **圆角规范**：小徽章 `4px`、按钮与输入控件 `6px`、列表项与工具条目 `8px`、工作区面板与模态框 `10px`

## 5. 图标与视觉资源

- 统一采用单一线性图标（`lucide-react`，线宽 `1.75`，常规尺寸 `16px`–`18px`）。
- 应用图标使用 WinKit 原创几何工具箱图标，不复用或模仿参考产品的图标、配色与截图素材。

## 6. 核心布局与交互状态

- **主体结构**：左侧固定导航栏（首页、收藏、最近使用、已上线工具快捷入口、底部设置） + 顶部工具栏（当前视图标题、全局搜索入口 `Ctrl+K`、运行中任务指示、主题/语言快捷指示） + 主工作区。
- **工具首页**：顶部即时过滤框 + 范围筛选（全部可用 / 收藏 / 最近使用 / 分类） + 高信息密度工具列表，标明稳定编号（如 `D01`、`D03`、`I03`）与当前实现边界，绝不展示未实现的假按钮或空壳入口。
- **工具工作区**：统一采用“输入/预览 + 参数控制 + 输出/校验结果”的平铺分栏结构，禁止多层卡片套卡片。
- **状态与无障碍**：
  - 所有交互控件具备明确的 `default`、`hover`、`focus-visible`（2px 清晰外轮廓）、`selected`、`disabled`、`loading`、`error` 状态。
  - 完整支持 `Tab` 顺序聚焦、`Enter`/`Space` 触发、`Esc` 关闭弹层或清空检索、`Ctrl+K` 聚焦工具搜索。
  - 所有输入框、滑块、颜色选择器与图标按钮均绑定显式 `<label>` 或 `aria-label`，错误信息通过 `role="alert"` / `aria-live="polite"` 传达。
  - 过渡动画控制在 `120ms` 以内的透明度或边框色变化，严格遵循 `@media (prefers-reduced-motion: reduce)` 关闭非必要过渡，动画绝不阻塞或延迟文件计算。
