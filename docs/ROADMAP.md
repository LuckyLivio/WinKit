# WinKit 阶段路线图 (ROADMAP.md)

## 项目范围与基线原则

- **目标平台**：Windows 11 x64，本地优先，简体中文（`zh-CN`）与英文（`en-US`）双语，无遥测、无账号、无云端上传。
- **应用标识**：`com.luckylivio.winkit`（固定不变，保障用户态覆盖安装与偏好继承）。
- **基线规模**：冻结为 8 大分类共 **102 项工具**（`V01–V15`、`A01–A05`、`I01–I13`、`P01–P23`、`T01–T09`、`F01–F05`、`S01–S18`、`D01–D14`）及 10 项公共能力（`C01–C10`），详见 [PARITY_MATRIX.md](./PARITY_MATRIX.md)。
- **上架准则**：应用界面仅暴露当前阶段已真实闭环并通过验证的工具入口，绝不放置空页面或不可用占位按钮；仅完成子集能力时在对照表中如实标记为`部分实现`；完成自动验证与真实 Windows 验证但未经用户逐项确认前保持为`待验收`。
