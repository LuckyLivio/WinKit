# WinKit 阶段路线图 (ROADMAP.md)

## 项目范围与基线原则

- **目标平台**：Windows 11 x64，本地优先，简体中文（`zh-CN`）与英文（`en-US`）双语，无遥测、无账号、无云端上传。
- **基线规模**：冻结为 8 大分类共 **102 项工具**（`V01–V15`、`A01–A05`、`I01–I13`、`P01–P23`、`T01–T09`、`F01–F05`、`S01–S18`、`D01–D14`）及 10 项公共能力（`C01–C10`），详见 [PARITY_MATRIX.md](./PARITY_MATRIX.md)。
- **上架准则**：应用界面仅暴露当前阶段已真实闭环并通过验证的工具入口，绝不放置空页面或不可用占位按钮；仅完成子集能力时在对照表中如实标记为`部分实现`。

## 本轮（阶段 0–1）严格边界

1. **本轮实现**：
   - 应用壳层与公共能力子集：首页可用工具列表、搜索（`C01`）、收藏（`C02`）、最近使用（`C03`）、会话内状态保留（`C04` 子集）、后台流式任务进度/取消与关闭窗口拦截提示（`C06` 子集）、主题/语言设置持久化（`C07` 子集）。
   - `D01` JSON 格式化与校验（完整核心闭环：无损数字精度保真、格式化/压缩、精确行列报错、键排序可选、文件打开/保存、复制/清空）。
   - `D03` 哈希工具（第一批子集：UTF-8 文本与本地大文件流式 SHA-256、真实字节进度、取消、期望摘要归一化比对；MD5/SHA-1/SHA-384/SHA-512 留阶段 2）。
   - `I03` 截图美化（第一批子集：PNG/JPEG 导入与拖放、纯色背景、留白、抗锯齿圆角、柔和阴影、原始比例 / `1:1` / `16:9` 画布、不拉伸原图的高清 PNG 导出与尺寸内存保护；渐变/自定义背景图/系统抓图联动留阶段 3）。
2. **本轮明确不做**：
   - 不创建其余 99 项工具的空壳页面、未接线按钮或占位处理器。
   - 不实现系统托盘常驻、开机自启、全局快捷键、CLI/MCP、系统级截屏捕获、OCR、视频/音频转码或云端联网逻辑。
   - 完成阶段 1 验证与文档交付后立即停止，不自行进入阶段 2。
