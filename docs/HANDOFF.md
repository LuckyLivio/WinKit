  - 已在 `0.1.0` 开发版、Release 与安装版实测复现窗口点击 `×` / `Alt+F4` 无法退出的确切根因（Tauri 2 注册 `onCloseRequested` 后自动 `prevent_close()`，收尾调用 `window.destroy()` 因缺少 `core:window:allow-destroy` 权限被 IPC 拒绝；同时修复了 StrictMode 异步监听泄漏与退出未等待工作线程释放句柄的问题）。

  - 扩展 `D03` 单遍分块流式计算 `MD5`、`SHA-1`、`SHA-256`、`SHA-384`、`SHA-512`（保留多文件批处理在阶段 2C，故仍标为`部分实现`）。

  - 已完成从已安装版本原地覆盖升级至 `v0.2.0`、偏好保留核验、真实桌面流程验证及远端 GitHub Actions CI 校验。

1. **阶段 2B（其余开发者工具）**：
   - 纯本地无阻塞项：`D05` JWT 本地解码与 HS256/384/512 验签、`D07` 文本与文件 Diff 对比、`D08` 正则表达式测试（带后台超时熔断）、`D09` 链接跟踪参数清理、`D11` Unicode 隐形与混淆字符检查、`D12` Lorem Ipsum 生成、`D13` 随机密码与助记短语生成、`D14` CSV ↔ JSON / Markdown 互转。

2. **阶段 2C（文件工具与哈希批处理）**：
   - 纯本地无阻塞项：`D03` 多文件批量哈希校验、`F01` 二维码生成与识别、`F02` 批量重命名（全量冲突预览 + 事务回滚）、`F03` 重复文件查找（三级流式比对 + 移入 Windows 回收站）、`F04` 压缩与解压（严格防 Zip Slip，RAR 解码库方案在 2C 核定）。
