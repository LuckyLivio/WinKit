- **阶段 2B1（`v0.3.0`）交付闭环（共 12 项真实可用桌面工具）**：
  1. **退出准入同步与进度终态修正**：将文件副作用任务的 `TaskTokenGuard` 登记前移至 `spawn_blocking` 入队之前；新增 `request_window_close` 在同一互斥锁内完成空闲关闭判断与 `shutting_down` 置位，并与前端 `shutdownGate` / Worker 终止联动；修正失败或取消事件不再统一填充 `percent: 100` 且补齐真实错误码与脱敏错误信息。
  2. **`D05` JWT 本地解码与验签**：三段式 JWS（大整数零损保真）、五段式 JWE 保护头识别、三维度状态分离（结构/签名/NumericDate 实时核对）及原始 `header.payload` 片段本地 `HS256`/`HS384`/`HS512` 恒定时间验签（拦截 `crit`，区分 `alg=none`）。
  3. **`D07` 文本与文件差异对比**：并排与内联视图、行内词/字符级高亮、BOM/CRLF/LF/末尾无换行识别与二进制拦截、忽略空白/大小写展示过滤，以及经 `git apply` 验证可精确还原目标文本的 Unified Diff 复制与 `.patch` 另存（单侧上限 `4 MB / 50,000 行`）。
  4. **`D08` 正则表达式测试**：明确标注 **ECMAScript / JavaScript `RegExp`** 引擎，编译/匹配/替换隔离在独立同源模块 Web Worker 中，主线程看门狗执行 `2000 ms` 真 `worker.terminate()` 抢占终止（已在真实安装版 WebView2 实测高回溯超时与恢复）。
  5. **`D11` Unicode 隐形与混淆字符检查**：内嵌离线 **Unicode 16.0.0** 官方数据与 UTS #39 `skeleton` 候选提示，支持双向定位、注意项筛选及默认保留 Emoji `ZWJ` 与波斯语 `ZWNJ` 的可预览非破坏性清理。
- **验收状态边界**：全部 12 项已启用工具验收状态统一保持为 `待验收`（其中 `D02`、`D03`、`D05`、`D06`、`D07`、`D08`、`D11`、`I03` 因存在已记录的规模/引擎/高阶子项边界保持实现状态为 `部分实现`）；用户原始退出反馈仍保持“已修复可复现缺陷并加固并发准入边界，待用户复测”。
