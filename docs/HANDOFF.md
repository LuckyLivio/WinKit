- **阶段 2B2（`v0.4.0`）交付闭环（共 16 项真实可用桌面工具）**：
  1. **范围与单位校正（检查点 0）**：依据原版公开详情页核实 `D05`（已完整覆盖 `HS256`/`HS384`/`HS512` 共享密钥验签、公钥算法仅解码、JWE 仅读头部，标记为 `待验收`；公钥验签与 JWE 解密属未立项可选增强）、`D07`（保留每侧 `4 MiB / 50,000 行` 与原版公开 `200,000 行` 的真实规模差异；移除目录递归/三方合并/二进制对比等无来源欠账）、`D08`（统一为 `regexCore.ts` 真实常量：`16,384` UTF-16 代码单元表达式、`2 MiB` 文本、`2,000` 处匹配、`2,000 ms` Worker 硬终止；移除无依据的多文件正则欠账）、`D11`（`512 KiB / 50,000 码点`，区分原版范围与无来源的 IDNA/字体渲染扩展），并将命令名统一为实际符号（`save_text_file`、`hash_file_multi`、`codec_transform_file`、`codec_save_output`、`export_beautified_png`、`read_diff_text_file`、`read_tabular_text_file`、`request_window_close`、`begin_graceful_shutdown`、`abort_graceful_shutdown`）。
  2. **`D09` 链接跟踪参数清理与已知跳转解包**：基于本地规则库（`2026.11-r1`）支持单条与批量链接清理（`1 MiB / 5,000 行`），区分通用参数与严格域名边界下的站点专属参数，原样保留 `+`/`%20`/`%2B`/`%252F`/`~`、重复项、空值、`#fragment` 及疑似签名链接，离线单层逐跳解包 Google/Facebook/Instagram/Outlook Safe Links/LinkedIn 包装（最多 5 层），并提供一次性剪贴板预览与“仅纯链接时写回替换”。
  3. **`D12` Lorem Ipsum 占位文本生成**：基于古典拉丁语固定词表按词（`1–5,000`）、句（`1–500`）、段（`1–100`）离线输出纯文本、HTML `<p>` 段落或 Markdown，经典开头严格计入总数且 HTML 标签不计入正文词数。
  4. **`D13` 随机密码与口令短语生成**：使用 OS CSPRNG（Rust `OsRng` / Web Crypto `getRandomValues`）32 位区间无偏拒绝采样生成密码（`8–128` 字符，含排除易混字符 `0Oo1lI|` 与有界拒绝采样必含类约束）与英文口令短语（Passphrase，`3–12` 词，EFF `7,772` 纯字母词表独立有放回抽样），按生成模型容斥/对数公式估算熵与强度，默认掩码展示。
  5. **`D14` CSV ↔ JSON 与 Markdown 表格转换**：独立可取消 Web Worker（接入 `shutdownGate` 与请求序号防陈旧覆盖）执行 **CSV ↔ JSON** 及 **CSV / JSON → Markdown 表格** 转换（输入 `8 MiB` / 输出 `16 MiB`），采用 RFC 4180 状态机与 `D01` 无损 JSON AST 全链路保真 `00123`、`9007199254740993`、`19.90`，支持嵌套对象 `address.city` 展开与点号键冲突策略、分号/紧凑 JSON 数组及可选前置 `'` 电子表格公式保护预览。
- **验收状态边界**：全部 **16 项**已启用入口用户验收状态均为 `待验收`（其中 `T08`、`T09`、`D01`、`D04`、`D05`、`D12`、`D13`、`D14` 共 8 项实现状态为 `待验收`；`I03`、`D02`、`D03`、`D06`、`D07`、`D08`、`D09`、`D11` 共 8 项因已记录的规模/引擎/监听阶段差异保持实现状态为 `部分实现`）；用户原始偶发退出体验继续保持“待日常复测确认”。
