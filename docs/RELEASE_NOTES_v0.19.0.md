# WinKit v0.19.0 发行说明草稿（候选待审核）

> **发布状态声明**：本文档为 **`v0.19.0` 发布候选（Release Candidate）发行说明草稿**，尚未创建正式 Git 标签或公开发布 GitHub Release。公开下载页仍严格对应既有正式版 [`v0.18.0`](https://github.com/LuckyLivio/WinKit/releases/tag/v0.18.0)；正式标签与公网发布将在本候选包与发布准备 PR 审核通过后由 `main` CI 产物执行。

## 版本概述 — 阶段 6A：本地离线 OCR、语音转写、图片抠图与文本/PDF 朗读

本版本面向 Windows 11 x64，新增 **`6` 项**独立本地工具（`T03`、`T04`、`P04`、`T01`、`I04`、`T06`（`部分实现`）），并将既有 **`A02` 录音机**、**`V02` 视频烧录字幕**与侧栏共用能力 **`C08` PDF 快速预览**分别接入离线语音转写、自动字幕与 PDF 按页朗读闭环。全应用已启用本地工具由 `66` 项增至 **`72` 项**（`待验收` `62` 项、`部分实现` `10` 项；另含侧栏共用能力 `C08`「PDF 快速预览」，不计入 102 项工具条目数）。全部识别、转写、抠图与朗读均在本机离线执行，无遥测、无账号、不向云端上传用户文件或文本。

## 本版新增与升级功能（按实际实现状态）

1. **`T03` 图片与扫描件文字提取（OCR）**（新增，`待验收`）
   - 离线中英混排多图与多页扫描 PDF 识别，隔离运行于 `winkit.exe --ocr-worker`（Windows Job Object `2 GiB` 限额、取消/关窗即时回收）。
   - 提供逐行坐标结构化结果、预览复制、手工校对保留与显式重新识别，以及保护队列全部源文件的防覆盖 TXT/JSON 批量导出。
2. **`T04` 屏幕区域取字**（新增，`待验收`）
   - 复用 DPI 感知多屏框选（`PerMonitorV2` 坐标矫正），截图仅驻留会话内存零落盘（共享 LRU 缓存淘汰后可无损恢复重新识别），一键复制到剪贴板，支持推理中确认退出即时回收子进程。
3. **`P04` 扫描版 PDF 转可搜索**（新增，`待验收`）
   - 逐页检测是否已有可选文字层并仅对扫描页运行离线 OCR；通过 `FPDF_DeviceToPage` 精确仿射变换适配 `0°/90°/180°/270°` 四旋转角，以单 `TJ` 文本对象写入不可见 Unicode 文字层（保留原扫描清晰度）。
   - 覆盖确认严格绑定完整转换请求（切档/改参数即失效），中途取消保护既有输出文件，转换结果可直接用于 `C08` 全文检索、浏览器拖选复制以及 `C08 → T06` 按页朗读。
4. **`T01` 离线音视频转写**（新增，`待验收`）
   - 隔离运行于 `winkit.exe --asr-worker`（Windows Job Object `2 GiB` 限额），支持中英混排/多语自动检测与 ITN 标点数字规范化；统一处理非零容器起点、音轨延迟与音轨中途时间空洞。
   - 提供内嵌音视频联动试听、分段时间戳与正文校对、顺序/重叠校验与一键修正、防覆盖 TXT/SRT 统一清洗导出及源媒体保护。
5. **`A02` 录音机转写联动**（升级至 `待验收`）
   - 录音保存后新增主操作「转写这段录音」直达 `T01`；`T01` 转写运行中自动暂存待处理录音且跨切页保留，已有手工校对稿时替换前先确认并先校验新文件有效且含音轨。
6. **`V02` 视频自动字幕闭环**（升级至 `待验收`）
   - 为含音轨视频提供「从当前视频生成字幕」送往 `T01`，并在 `T01` 导出 `.srt` 后提供「应用到原视频」原子成对回填 `V02` 烧录硬字幕；保留手动导入 SRT/VTT 流程，并通过 `fs_guard::commit_temp_file` 加固原子防覆盖与源视频/源字幕只读保护。
7. **`I04` 图片抠图去背景**（新增，`待验收`）
   - 隔离运行于 `winkit.exe --matting-worker`（Windows Job Object `4 GiB` 限额，关闭 ONNX CPU Arena 压降峰值内存与空闲工作集），支持 EXIF 方向矫正、原图透明通道乘法合成与透明区零溢色。
   - 提供原图/抠图像素对齐滑块对比、透明棋盘格与纯色背景预览、主体紧凑裁切+边距与实时像素预估、透明 PNG/WebP 与纯色 PNG/JPEG/WebP 防覆盖导出、系统图片剪贴板读写、合成阶段取消重试及一键送往 `I03`/`I12`/`I13`。
8. **`T06` 文本朗读 + `C08` PDF 按页朗读**（新增，`部分实现`）
   - 调用 Windows 本机离线语音（WinRT OneCore + 去重 SAPI Desktop），隔离运行于 `winkit.exe --tts-worker`（Windows Job Object `1 GiB` 限额、退出与清空自动清理 `%TEMP%\winkit-tts\` 临时音频）。
   - 支持粘贴文本、UTF-8 `.txt` 文件以及在 `C08` 中「朗读当前页 / 朗读所选页」（含经 `P04` OCR 转换的可搜索 PDF，纯扫描页提示一键跳转 `P04`；全链路贯彻 `1 MiB / 200,000` 字符上限且无重复全文负载、准确区分实际朗读页/扫描页/超限省略页、提取严格绑定已校验文档与页面生命周期、复用 `T01` 待处理与确认交接体验保护 `T06` 草稿与试听）；支持 `0.5×–2.0×` 语速、内置 `<audio>` 试听、纯离线无损 WAV 导出与保留原采样率/实测码率档位（`ffprobe` 回读）的本地 FFmpeg MP3 导出，源 `.txt`/`.pdf` 由后端结果记录强制保护不可覆盖。

## 诚实范围、保留项与安全边界

1. **功能矩阵保留项（详见 [docs/PARITY_MATRIX.md](./PARITY_MATRIX.md)）**：
   - **`部分实现`（`10` 项）**：`T06`（尚不含 Office `.docx`/`.xlsx`/`.pptx` 文档直接朗读，且 Windows 无 Apple Personal Voice）、`I10`、`I11`（自动 OCR 区域打码留后续补齐）、`D02`、`D06`、`D07`、`D08`、`D09`、`D10`、`D11`。
   - **`平台替代待确认`（`16` 项）**：阶段 6B 端侧大模型项 `T02`、`T05`、`T07`（待用户确认本地大模型方案）及 `P01`、`P20`、`P21`、`S01`、`S03`、`S06`、`S08`、`S09`、`S13`、`S14`、`S15`、`S16`、`S18`。
   - **`未开始`（`14` 项）**：留待阶段 7–9 推进。
2. **隔离与签名边界**：
   - `--ocr-worker`、`--asr-worker`、`--matting-worker`、`--tts-worker` 与 `--pdf-worker`/`--qpdf-worker` 均通过 Windows Job Object 实现崩溃隔离、内存限额与取消/关窗进程回收，**不等同于完整操作系统级安全沙箱**。
   - 本候选安装包未做 Authenticode 代码签名（`NotSigned`）；离线行为经最小 `PATH` + 失效代理 + `Get-NetTCPConnection` 零外部非回环 TCP 连接实测验证，物理断网/飞行模式实机体验与 SmartScreen 提示仍按项目规则如实标注。

完整候选验证与覆盖升级实测记录见 [docs/VERIFICATION.md](./docs/VERIFICATION.md)。
